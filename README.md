## Описание проекта

Система домашнего медиасервера, написанная на Python с использованием **Flask** и **aiogram 3**.

Проект решает простую задачу: хранить видео, фото и музыку на домашнем компьютере и получать к ним доступ с любого устройства — без облачных сервисов вроде Google Drive или Яндекс.Диска.

Пользователь кладёт файлы в нужные папки на ПК, запускает синхронизацию — и файлы становятся доступны через веб-браузер или Telegram-бота по прямой ссылке для просмотра и скачивания.

Поскольку Telegram заблокирован в РФ, бот размещён на хостинге **PythonAnywhere** и работает независимо от локальной машины. Локальный Flask-сервер раздаёт файлы по HTTP внутри домашней сети.

---

## Возможности

- 🔍 Поиск файла по части названия через Telegram-бота
- 🔗 Получение прямой ссылки на файл для просмотра или скачивания в браузере
- 🎬 Поддержка видео (MP4, MKV), фото (JPG, JPEG, PNG, RAW) и аудио (MP3, WAV, OGG)
- 🔄 Синхронизация папок с базой данных через `sync_files.py`
- 🌐 Веб-интерфейс для просмотра медиатеки в браузере
- 📁 Загрузка файлов через веб-интерфейс
- 📊 Статистика по количеству файлов и пользователей

## Инструкция по запуску на Windows

### 1. Клонирование проекта

```bash
git clone https://github.com/<ваш-логин>/<ваш-репозиторий>
cd <ваш-репозиторий>
```

### 2. Создание и активация виртуального окружения

```bash
# Создать виртуальное окружение
python -m venv venv

# Активировать окружение
.\venv\Scripts\Activate.ps1
```

> Если PowerShell выдаёт ошибку выполнения скриптов, выполните один раз:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

### 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка config.py

Откройте `config.py` и укажите:

```python
BOT_TOKEN = "ваш_токен_от_BotFather"   # токен Telegram-бота
LOCAL_SERVER_URL = "http://192.168.x.x:5000"  # локальный IP вашего ПК
```

Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.
Локальный IP узнать командой `ipconfig` в командной строке.

### 5. Добавление файлов

Положите медиафайлы в нужные папки:

```
C:\WORKS\Service\Music\   — аудио (MP3, WAV, OGG)
C:\WORKS\Service\Video\   — видео (MP4, MKV)
C:\WORKS\Service\Photo\   — фото  (JPG, JPEG, PNG, RAW)
```

### 6. Синхронизация базы данных

```bash
python sync_files.py
```

Скрипт просканирует папки и внесёт все файлы в `service.db`.

### 7. Запуск сервера

**Через .bat файл** (рекомендуется):

Дважды кликните на `ЗАПУСТИТЬ.bat`

**Или через терминал:**

```bash
python main.py
```

Сервер запустится по адресу `http://0.0.0.0:5000`. Для остановки нажмите `Ctrl+C`.

### 8. Передача базы данных боту

Скопируйте файл `service.db` в директорию проекта на PythonAnywhere вручную (через файловый менеджер сайта). После этого бот будет видеть все файлы и сможет выдавать ссылки на них.

## Известные ограничения

- Telegram заблокирован в РФ — для работы бота локально необходим VPN
- Сервер доступен **только в локальной сети** (домашняя сеть Wi-Fi / LAN)
- База данных передаётся на хостинг **вручную** после каждого обновления файлов
- Максимальный размер загружаемого файла через веб — **100 МБ**
